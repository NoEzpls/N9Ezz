# N9Ezz 0.4.6 Experimental

Сборка для **Minecraft 1.21.11, Java 21 и собственного Universal Loader**.
`1.21.4` в имени скачиваемого файла — выбранное название, **не версия игры**.
Переноса на Minecraft 1.21.4 нет.

Возвращены старое меню Pulse и его 83 модуля. Сохранены семь текущих модулей
N9Ezz: KillAura, Triggerbot, AimBot, Hitboxes, AutoTotem, IncreasedDamage и Speed.
Всего в реестре 90 модулей. CF Assistant не входит.

Обычный заголовок меню — **N9Ezz**. `/pv hide` выключает модули N9Ezz, скрывает
вкладку «Читы» и переключает заголовок на **PulseVisuals**. Старые вкладки
Visuals / HUD / Utilities и функции Pulse остаются доступны. `/pv show` возвращает
вкладку и заголовок N9Ezz без автоматического включения боевых модулей.
Это режим интерфейса, а не выгрузка клиента или удаление файлов и журналов.

## Установка

1. Один раз запустите обычный Minecraft **1.21.11** в своём лаунчере.
2. Закройте игру и лаунчер. Через Java 21 запустите
   `1.21.4-Universal-Loader-0.4.6-experimental.jar` и выберите основную папку
   Minecraft, где находятся `versions`, `libraries` и `launcher_profiles.json`.
   Это установщик, его не нужно помещать в `mods`.
3. Выберите созданный профиль **Client profile (Minecraft 1.21.11)** либо имя,
   сохранённое вами ранее: установщик покажет фактическое имя после установки.
4. Сначала проверьте меню и настройки в одиночном мире.

```text
java -jar 1.21.4-Universal-Loader-0.4.6-experimental.jar --install --game-dir "путь/к/.minecraft"
```

Данные сборки находятся в `profiles/client-1.21.11` внутри выбранной папки игры.
Установщик создаёт отдельную версию `Client-Universal-1.21.11`, библиотеку
`dev.clientprofile:universal-loader` и служебный каталог `.client-profile`.
Официальные JAR Minecraft не подменяются. Технические Java-пакеты, mod ID `pulse`
и имена сторонних библиотек сохранены для совместимости. Нейтральные названия
не означают, что наличие мода невозможно обнаружить.

Отсутствующие настройки переносятся из прежней `pulsevisuals-universal`, затем
из `n9ezz-universal`. Уже существующие настройки новой установки имеют приоритет;
исходные папки, профили и файлы сохраняются. Личные журналы и сторонние моды не
переносятся. Новые пути настроек: `config/client-profile`, `client-profile/config`
и `client-profile.cfg` относительно папки профиля.

Исправление установщика 0.4.5 сохранено: профиль определяется по версии и
нормализованному абсолютному `gameDir`, даже если лаунчер убрал служебную метку
или поменял ключ. При конфликте чужой профиль сохраняется и создаётся отдельный.
Перед изменением сохраняется точная резервная копия `launcher_profiles.json`.

## Боевые изменения

После установки выполните **`/pv combat`**, чтобы применить новый профиль.
Старые конфиги сохраняются и иначе могут восстановить прежние ограничения.
Команда включает боевые модули, поэтому применяйте её там, где собираетесь их
проверять. Профиль задаёт FOV 360°, сопровождение 5 блоков, заряд 95%, паузу после
мыши 0 мс, дополнительную задержку попыток Aura 0–10 мс и второй удар. Speed
выключается; его свободное движение выбирается для следующего включения.

**Hitboxes / Triggerbot.** Выбор точки переписан: проверяется ближайшая точка и
альтернативные видимые части настоящего тела. Закрытая ближайшая точка больше
не исключает всю цель. У границы дальности проверяется сама ближайшая грань.
Triggerbot ограниченно удерживает цель во время доводки, не теряя её только из-за
промежуточного поворота. Расширенная область помогает выбрать цель; итоговая атака
проверяет настоящее тело, дальность и препятствия. Ручной удар без автоботов
сохраняет обычную геометрию. Серверные хитбоксы этим не увеличиваются.

**KillAura.** Отдельная «Дальность сопровождения» позволяет заранее выбирать и
видимо отслеживать боковую или заднюю цель. Дальность атаки отдельно ограничена
атрибутом игрока. Сопровождение на пяти блоках не означает удар с пяти блоков.
Доступная для атаки цель имеет приоритет перед дальней целью сопровождения,
кроме явно включённого удержания цели или общего режима Juggernaut.
Смена цели не сбрасывает лимит поворота. Пауза после ручного движения мыши по
умолчанию 0 мс; её можно увеличить настройкой.

«Второй удар сразу» выполняет ровно один обычный повтор attack/swing после
первого и включён новым профилем. Серверные заряд оружия и неуязвимость сохраняются,
поэтому второй вызов не равен гарантированному дополнительному урону.
«В воздухе только криты» ждёт настоящих условий крита: падения, достаточного
заряда и отсутствия ограничений. При подъёме или ином полёте крит не создаётся
подменой `OnGround`. Отключение этой настройки разрешает обычные воздушные атаки.

**Speed.** «Свободное движение» компенсирует автоповороты Aura/Triggerbot при
удержании WASD, включая поворот до первого опроса клавиш. Ручное движение мыши
продолжает рулить. После отпускания клавиш новый шаг следует текущему направлению
камеры. Speed не меняет yaw/pitch; включённая Aura всё ещё поворачивает камеру
для наведения. Свободный режим имеет приоритет над преследованием. Juggernaut
явно включает режим преследования.

Сила Speed 1–100 задаёт желаемую горизонтальную скорость ×1,04–×5 без накопления
множителя. Сервер может её отклонить. Коррекция позиции ставит Speed на паузу до
ручного возобновления; входящая серверная скорость получает 10 тиков без вмешательства.
Исправлено затирание причины такой паузы последующим пакетом скорости. Задержки
пакетов ради имитации лагов не добавлены.

## Команды

| Команда | Действие |
| --- | --- |
| `/pv combat` или `/cfg pvp` | Новый боевой профиль; обычно Aura, Hitboxes и AutoTotem |
| `/pv juggernaut` | Общая цель, Aura + Hitboxes + преследование Speed ×2 |
| `/pv juggernaut off` | Остановить общий режим и боевые модули N9Ezz |
| `/pv hide` | Выключить N9Ezz, скрыть «Читы», заголовок PulseVisuals; функции Pulse доступны |
| `/pv show` | Вернуть интерфейс N9Ezz без включения боевых модулей |
| `/pv status` | Причины ожидания модулей, дальность, клиентские счётчики и коррекции |
| `/cfg combat` | Диагностика общего диспетчера автоатак |
| `/pv speedresume` | Снять паузу Speed; сам модуль включается отдельно |

Поддерживается `.pv ...`. Эти команды локальные. При остановке атак или движения
сохраните `/pv status` и `/cfg combat` **до** переключения модулей: повторное
включение может сбросить состояние. Клиентские запросы и отправки не являются
подтверждением полученного сервером урона.

IncreasedDamage до +8 действует только на встроенном сервере одиночной игры.
Обязательные серверные сообщения, телепортации и скорость не игнорируются.
Крит при любом полёте, расширение серверного тела, обход RaidMine и отсутствие
банов не подтверждены. Дуэль с expa и графический запуск этой версии в облаке
не выполнялись.

## Исходники и проверка

`verification.json` и архив `test-reports` содержат результаты конкретной сборки.
Проверяются геометрия, реальные контроллеры и адаптеры модулей, совместное
движение, 90 модулей, меню, команды, миграция, загрузчик и сетевые регрессии.
Тесты на модели мира не означают успешное испытание на сервере.

Полных исходников оригинального Pulse нет. Архив исходников содержит собственные
контроллеры, патчи, тесты и исходники Loader, а также рецепт наложения на точный
входной клиент с проверкой SHA-256. Это не полный исходный код движка Pulse.
Присланные личные конфиги, логи, переписка, Minecraft и сторонние клиенты в релиз
не входят.

Подробности: `CHANGELOG-RU.md`, `docs/BUILD.md`, `docs/TARGETING-046-RU.md`,
`docs/NETWORK-RU.md`. Сравнение в `docs/COMBAT-COMPARISON-RU.md` относится к
отдельным методам старой 0.4.3 и expa, а не к дуэли нового релиза.
