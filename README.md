# N9Ezz 0.4.7 Experimental — Speed

Изменены Speed и названия установки. KillAura, Triggerbot, Hitboxes, AimBot,
AutoTotem, IncreasedDamage и меню сохранены из 0.4.6; сборка проверяет побайтное
совпадение 29 связанных классов с опубликованным JAR 0.4.6.

Игра: **Minecraft 1.21.11, Java 21, собственный N9Ezz Universal Loader**.
`fabric-loader-0.19.3-1.21.4` — выбранное имя файла, профиля и каталогов.
Оно не меняет версию Minecraft и не устанавливает официальный Fabric Loader 0.19.3.

## Установка

1. Один раз запустите ванильный Minecraft **1.21.11** в лаунчере.
2. Закройте игру и лаунчер. Запустите **`fabric-loader-0.19.3-1.21.4.jar`**
   через Java 21 и укажите основную папку `.minecraft`.
   Это установщик; класть его в `mods` не нужно.
3. Выберите профиль **`fabric-loader-0.19.3-1.21.4`** и запустите игру.
4. В меню откройте Speed и включите модуль. Новые настройки перечислены ниже.

```text
java -jar fabric-loader-0.19.3-1.21.4.jar --install --game-dir "путь/к/.minecraft"
```

Новая папка игры: `.minecraft/profiles/fabric-loader-0.19.3-1.21.4`.
Профиль версии: `versions/fabric-loader-0.19.3-1.21.4`.
Служебные данные: `.fabric-loader-0.19.3-1.21.4`.
Настройки внутри папки игры: `config/fabric-loader-0.19.3-1.21.4`,
`fabric-loader-0.19.3-1.21.4/config` и `fabric-loader-0.19.3-1.21.4.cfg`.

Настройки копируются сначала из `profiles/client-1.21.11`, затем из
`pulsevisuals-universal`, затем из `n9ezz-universal`. Уже существующие новые
настройки имеют приоритет. Старые файлы и профили сохраняются для возврата;
установщик не удаляет их. Логи и сторонние моды не переносятся.
Если запрошенное имя версии уже занято другой установкой Fabric,
установщик сообщает `VERSION_ID_CONFLICT` и сохраняет её файлы.

## Speed

| Настройка | По умолчанию | Действие |
| --- | --- | --- |
| Импульсный Speed | Включён | Чередовать активную фазу и фазу без добавочного разгона |
| Тиков разгона | 1 | Длительность активной фазы, 1–20 тиков |
| Тиков без разгона | 1 | Длительность паузы, 1–100 тиков |
| Автоповтор после коррекции | Включён | Ждать 20 тиков и повторить; максимум 3 повтора за включение |
| Свободное движение | Включено | Сохранять управление WASD при автоповоротах боевых модулей |
| Сила Speed | Прежнее сохранённое значение; для новой настройки 15 | Шкала 1–100 и прежний расчёт скорости сохранены |

Обычно один игровой тик занимает 50 мс. При настройке 1/1 получается
10 импульсов в секунду при 20 TPS. В паузе модуль не записывает новую скорость:
инерция, трение, обычный ввод и серверная скорость продолжают обрабатываться.
Отключение «Импульсный Speed» возвращает непрерывный режим.

Миллион переключений внутри тика не создаёт миллион шагов движения. В коде
нет фонового цикла переключений: фаза определяется номером тика. На игрока
допускается одна запись разгона за тик, включая повторное включение модуля.
Скорость не умножается на уже ускоренную скорость; вертикальное движение
и направление камеры этот механизм не меняет.

После серверной коррекции сначала выполняется обычная обработка пакета.
При включённом автоповторе модуль ждёт 20 тиков. Входящий пакет скорости
может продлить ожидание до окончания его отдельного окна в 10 тиков.
После трёх возобновлений следующая коррекция останавливает Speed до ручного
включения или `/pv speedresume`. Отключённый автоповтор оставляет прежнюю
ручную паузу. Дисконнект, смена мира/игрока и `/pv hide` отменяют автоповторы.

`/pv status` показывает текущую фазу, причину ожидания, число коррекций и
использованные повторы. Это наблюдения клиента. Работу ускорения на RaidMine
и обход его проверок эта сборка не подтверждает.

## Остальные команды и интерфейс

Старые команды сохранены: `/pv combat`, `/cfg pvp`, `/pv juggernaut [off]`,
`/pv hide`, `/pv show`, `/pv status`, `/cfg combat`, `/pv speedresume`.
Для проверки только Speed не требуется применять `/pv combat`: эта команда
меняет сохранённые настройки боевых модулей и выключает Speed.

Обычное меню называется N9Ezz; после `/pv hide` — PulseVisuals. Сохранены
83 исходных модуля Pulse и 7 модулей N9Ezz. CF Assistant в сборку не входит.

## Проверки и исходники

Результаты сборки находятся в `verification.json` и
`fabric-loader-0.19.3-1.21.4-test-reports.zip`. Проверяются фазы импульсов,
миллион повторных вызовов внутри одного тика, предел автоповторов, обработка
коррекции/скорости/смены мира, реальные адаптеры настроек и перенос установки.
Отдельно проверяется неизменность боевых классов относительно 0.4.6.

Живой запуск Minecraft на Windows, игровой сеанс RaidMine и захват пакетов
в этой среде не выполнялись. Успех программных тестов не доказывает обход античита.

`fabric-loader-0.19.3-1.21.4-sources.zip` содержит исходники Loader, собственные
контроллеры и ASM-патчи. Полные исходники исходного движка Pulse недоступны;
сборка использует проверенный бинарный вход. Рецепт и контрольные суммы:
[docs/BUILD.md](docs/BUILD.md). История: [CHANGELOG-RU.md](CHANGELOG-RU.md).
