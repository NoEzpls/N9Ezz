# N9Ezz 0.5.0 Experimental

Инженерное обновление существующего клиента для **Minecraft Java 1.21.11,
Java 21 и собственного N9Ezz Universal Loader**. Сохранены меню, конфигурации,
83 модуля Pulse и 7 модулей N9Ezz. Это установщик отдельного профиля; его не
нужно помещать в `mods`. Обычным Fabric-модом проект не заменён.

## Изменения

- `TriggerV2Controller.tick`: повторный захват после потери цели проверяет срок
  памяти **до** обновления времени наблюдения. В 0.4.9 один краткий промах и
  долгая пауза в обработке тиков позволяли использовать просроченное подтверждение.
  Теперь такое возвращение ждёт установленный срок подтверждения заново.
- Короткая потеря цели в пределах памяти сохраняет прежнее подтверждение и часы
  частоты атак. Нулевая память не мешает непрерывному сопровождению. Значения CPS,
  заряда, дальности, доводки, критов и настройки других модулей не менялись.
- Сборка выбирает `java.exe`/`javac.exe` на Windows, использует UTF-8 и файлы
  аргументов javac для длинных путей. Добавлен `Build-Windows.ps1`.
- TestKit по умолчанию не исполняет код входного JAR; ошибки целостности всегда
  получают FAIL-отчёт. Добавлены проверки повреждений, метаданных и дубликатов.

Для потерянной цели после зависания может появиться предусмотренная настройкой
пауза подтверждения. Это исправление просроченного состояния, не увеличение
частоты атак и не измеренное улучшение результата дуэли.

## Установка

1. Установите Java 21 и один раз запустите ванильный Minecraft **1.21.11**.
2. Закройте игру и лаунчер. Запустите `fabric-loader-0.19.3-1.21.4.jar` и укажите
   основную папку `.minecraft`.
3. Выберите отдельный профиль `fabric-loader-0.19.3-1.21.4` в лаунчере.

```powershell
java -jar .\fabric-loader-0.19.3-1.21.4.jar --self-test
java -jar .\fabric-loader-0.19.3-1.21.4.jar --install --game-dir "$env:APPDATA\.minecraft"
```

Имя `fabric-loader-0.19.3-1.21.4` сохранено ради совместимости установленных
версий. Игра остаётся **1.21.11**, загрузчик остаётся N9Ezz. Это имя не означает
установку официального Fabric. Папка игры:
`.minecraft/profiles/fabric-loader-0.19.3-1.21.4`.

Существующие настройки и пользовательское имя профиля сохраняются. Установщик
делает резервную копию метаданных лаунчера, не удаляет старые профили и отказывается
заменять чужую установку с совпавшим ID. При повторной установке с теми же входами
проверяется отсутствие изменений. Настройки интерфейса и команды `/pv status`,
`/pv combat`, `/cfg pvp`, `/pv juggernaut`, `/pv speedresume`, `/pv hide` и `/pv show`
сохранены. Для изолированной проверки Triggerbot не применяйте общий профиль
`/pv combat`: он меняет сразу несколько боевых настроек.

## Сборка и проверка

Полный вызов и SHA-256 входов: [docs/BUILD.md](docs/BUILD.md).
Для Windows: [Build-Windows.ps1](Build-Windows.ps1). Нужны Python 3.10+, полный
JDK 21 и отдельно перечисленные проверенные входные JAR/архивы. Сборка работает
без сети, но не может восстановить недоступный полный исходник Pulse.

`verification.json` и `fabric-loader-0.19.3-1.21.4-test-reports.zip` содержат
результаты конкретного запуска. В ZIP включены `audit.json` и `audit.txt`.
Предварительно исходная 0.4.9 заново прошла 34 группы тестов; её JAR и исходники
воспроизвели опубликованные SHA-256. Новый тест сначала воспроизводит ошибку
на 0.4.9, затем проверяет исправленный контроллер.

Java-тесты выполняют реальные контроллеры с зависимостями-фикстурами, сетевые
классы, загрузчик и установщик с временными метаданными игры. Они не являются
запуском Minecraft или испытанием серверной регистрации урона. Windows GUI,
живой Minecraft, отдельный RaidMine-сеанс, захват пакетов, RTT и потери:
**SKIPPED/UNRUN**. Порядок локальной проверки описан в
[docs/GAMEPLAY-TEST-RU.md](docs/GAMEPLAY-TEST-RU.md).

Архитектура: [docs/ARCHITECTURE-RU.md](docs/ARCHITECTURE-RU.md).
История: [CHANGELOG-RU.md](CHANGELOG-RU.md). Ранее реализованные функции и их
ограничения описаны в [docs/RELEASE-049-RU.md](docs/RELEASE-049-RU.md).
Процент необнаружения и превосходство над другими клиентами не измерялись.
