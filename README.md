# PulseVisuals 0.4.5 Experimental

Обновление N9Ezz для **Minecraft 1.21.11, Java 21 и собственного Universal Loader**.
Доступны десять модулей: KillAura, Triggerbot, AimBot, Hitboxes, AutoTotem,
IncreasedDamage, Speed, Aspect Ratio, Optimization и Motion Blur. CF Assistant не входит.

Версия 0.4.5 исправляет установку поверх 0.4.3/0.4.4 при ошибке
`Profile key belongs to another installation`. Боевой клиент совпадает с 0.4.4;
изменены только установщик и проверки установки.

## Установка

1. Один раз запустите обычный Minecraft 1.21.11 в своём лаунчере.
2. Закройте Minecraft и лаунчер. Запустите `PulseVisuals-Universal-Loader-0.4.5-experimental.jar`
   через Java 21 и выберите основную папку Minecraft, где находятся `versions`,
   `libraries` и `launcher_profiles.json`. Это установщик, его не нужно класть в `mods`.
3. Откройте лаунчер и выберите **PulseVisuals Universal (experimental)** либо
   своё сохранённое имя профиля — установщик покажет его после завершения.
4. Сначала проверьте меню и настройки в одиночном мире.

Для установки из командной строки:

```text
java -jar PulseVisuals-Universal-Loader-0.4.5-experimental.jar --install --game-dir "путь/к/.minecraft"
```

Создаются отдельный профиль `PulseVisuals-Universal-1.21.11` и папка
`pulsevisuals-universal`. Установщик переносит отсутствующие файлы настроек
из `n9ezz-universal`; исходные файлы, старый профиль и существующие новые настройки
сохраняются. Сторонние моды и логи не копируются. Параметры памяти и Java из
старого управляемого профиля сохраняются. Повторная установка не переписывает
уже правильный `launcher_profiles.json` и его даты.

Лаунчер может убрать служебную метку `pulsevisualsManaged` или изменить ключ
профиля. Теперь обновление находит свою установку по версии и нормализованному
абсолютному пути `gameDir`, сохраняя пользовательское имя, параметры Java и даты.
Если нужный ключ занят другим профилем, тот остаётся на месте, а установщик
создаёт отдельный профиль с другим устойчивым ключом. Повторная установка
использует уже созданный профиль. Перед изменением сохраняется точная резервная
копия `launcher_profiles.json` в `.pulsevisuals/backups`.
Удалять профили или редактировать JSON для исправления этой ошибки не требуется.

Пользовательские пути теперь `config/pulsevisuals`, `pulsevisuals/config`,
`pulsevisuals.cfg`, `.pulsevisuals/builtin`; библиотека загрузчика устанавливается
в `libraries/dev/pulsevisuals`. Технические Java-пакеты, mod ID `pulse` и старые
форматы конфигураций сохранены для совместимости. Ручное переименование внутренних
файлов JAR или чужих папок не требуется.

## Новые боевые настройки

После установки выполните **`/pv combat`**: старые конфиги сохраняются и могут
восстановить прежние углы и задержки. Эта команда включает новый профиль с FOV
360°, быстрым поворотом до 180° за тик, подтверждением 0 мс, зарядом 95% и jitter
0–10 мс. Профиль выключает Speed и дополнительный удар, в том числе после Juggernaut.

KillAura полностью переведена на новый контроллер выбора, наведения и интервалов.
Она сначала выбирает цель и поворачивается, затем запрашивает обычную атаку.
Скрытый конус от мощности и скрытая минимальная задержка подтверждения убраны.

В настройках KillAura:

- **«В воздухе только криты»** — ждать падения, заряда >90% и настоящих условий
  крита. На земле работает отдельный порог заряда. Отключение разрешает обычные
  воздушные атаки; положение игрока и `onGround` не подменяются.
- **«Второй удар сразу»** — один дополнительный обычный вызов атаки и взмах
  после первого по той же цели, без повторной проверки заряда/луча. По умолчанию
  выключен. Второй вызов не отменяет серверные интервалы неуязвимости и не обещает
  дополнительный урон.
- **«Быстрый поворот», «Поворот за тик»** — видимый поворот к целям сбоку и сзади.
  Если лимита поворота не хватило, атака ждёт физического наведения.
- **«Jitter задержки»** — добавочная случайная задержка между попытками 0–N мс.
  Она не ускоряет таймер и не задерживает обязательные ответы серверу.

Hitboxes использует переписанную ограниченную геометрию выбора. Нижняя граница
остаётся у ног. При включённой «Доводке Triggerbot» Triggerbot наводится на
видимую точку настоящего тела. Расширение больше не считается достаточным
доказательством попадания. Серверные хитбоксы и дальность при этом не меняются.

Triggerbot переведён на новый контроллер: краткий уход прицела не сбрасывает
часы атаки и подтверждение той же цели. Настройка «Память цели» ограничивает это
время; вне физического попадания удара нет. Долгий промах требует нового подтверждения.

Speed меняет желаемую горизонтальную скорость клиента, сохраняя вертикальное
движение: сила 1 → ×1,04, 25 → ×2, 100 → ×5 базовой скорости. Множитель не
накапливается от тика к тику; Hight/Extra не меняют эту шкалу. «Преследовать слабую
цель» выбирает видимого игрока с меньшим суммарным HP и поглощением. После
серверной коррекции Speed остаётся на паузе; серверная скорость получает окно
10 тиков без вмешательства. Это клиентский разгон, а не подтверждённый баг сервера:
RaidMine может откатить или ограничить движение.

## Команды и общий режим

| Команда | Действие |
| --- | --- |
| `/pv combat` | Новый боевой профиль 360°; по умолчанию KillAura, Hitboxes, AutoTotem |
| `/pv juggernaut` | Общая цель с меньшим HP, KillAura + Hitboxes + Speed ×2, второй удар включён |
| `/pv juggernaut off` | Выключить общий режим и боевые модули |
| `/pv hide` | Выключить все десять модулей, закрыть меню и скрыть боевые карточки |
| `/pv show` | Вернуть интерфейс без автоматического включения модулей |
| `/pv status` | Состояние общего режима и причина паузы Speed |
| `/pv speedresume` | Снять паузу Speed; сам модуль включается отдельно |

Поддерживается `.pv ...`. Все команды локальные. `/cfg pvp` тоже применяет новый
боевой профиль. Juggernaut выбирает общую цель на тик в пределах 12 блоков;
Speed приближается, Aura атакует только в реальной разрешённой дистанции.
Одновременно два автобота не запускаются. Смена мира/игрока останавливает общий
режим, повторное включение только вручную. Это координация модулей, без обещания
превосходства над всеми клиентами.

Скрытие оставляет мод загруженным и не удаляет файлы или логи. Aspect Ratio,
Optimization и Motion Blur сохранены. IncreasedDamage до +8 действует только
на встроенном сервере одиночной игры. Обязательные сетевые ответы и серверная
скорость не отменяются. Незаметность для античита не подтверждена.

## Проверка и исходники

Полных исходников движка Pulse нет. В архив входят исходники собственного
загрузчика, изменений, тестов и рецепт наложения на точный входной JAR с проверкой
SHA-256. Это не полная пересборка исходного движка из Java-кода.

`verification.json` и ZIP с отчётами содержат результаты текущей сборки.
Проверяются новые контроллеры и их подключение к модулям, криты, часы атаки, выбор точек, команды, десять модулей,
перенос настроек, сетевые регрессии, загрузчик и установщик. Графический запуск
Minecraft, визуальное качество Blur и игра на RaidMine в облаке не выполнены.

Подробности: `CHANGELOG-RU.md`, `docs/BUILD.md`, `docs/NETWORK-RU.md`, `docs/COMBAT-COMPARISON-RU.md`.
Присланные личные настройки, логи, переписка и сторонние клиенты в релиз не входят.
