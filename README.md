# N9Ezz 0.4.2-six.1 Experimental

Сборка для **Minecraft 1.21.11, Java 21 и собственного N9Ezz Universal Loader**.
Она оставляет шесть доступных модулей: KillAura, Triggerbot, AimBot, Hitboxes,
AutoTotem и IncreasedDamage. Это обновление клиента `0.4.1-network.1` из присланной
сборки. CF Assistant в него не включён.

## Установка

1. Закройте Minecraft. Сохраните копию своей папки игры и конфигурации.
2. Запустите `N9Ezz-Universal-Loader-0.4.2-six.1-experimental.jar` через Java 21
   и выберите нужную папку игры. Не кладите установщик в `mods`.
3. Выберите профиль N9Ezz Universal для Minecraft 1.21.11 в лаунчере.
   Установщик использует существующий формат профиля; номер профиля Minecraft
   не является номером релиза установщика.
4. Сначала проверьте открытие меню и поведение в одиночном мире. Для отдельной
   установки можно указать новую папку игры командой ниже.

```text
java -jar N9Ezz-Universal-Loader-0.4.2-six.1-experimental.jar --install --game-dir "путь/к/папке/игры"
```

Настройки шести оставшихся модулей читаются в прежнем формате. Старые профили
не должны включать исключённые модули: регистрация и активация ограничены
списком из шести классов. Их старые служебные классы остаются внутри JAR,
поскольку другие части клиента ссылаются на них. Это сохраняет совместимость
связей классов, но не даёт включить прежние функции.

## Изменения поведения

- На земле автоатака разрешена при полном заряде оружия и попадании луча в цель.
- При подъёме в прыжке автоатака запрещена. При падении она разрешена только
  при настоящих условиях критического удара; положение и `onGround` не подменяются.
- Условия повторно проверяются перед отправкой: сменившаяся за тик цель,
  оружие или состояние игрока не должны приводить к устаревшему удару.
- Пока игрок использует предмет, включая еду и щит, автоатаки приостановлены.
  Бот не отпускает и не поднимает щит ради удара.
- Наведение и финальный луч автоатаки используют физическую геометрию цели.
  Обычный ручной выбор цели также проверяет настоящий хитбокс.
  Расширение Hitboxes остаётся клиентским инструментом выбора и отображения;
  оно не увеличивает серверную область попадания или дальность атаки.
- Скрытые множители HIGHT ×2,5 и EXTRA ×10 отключены. Сила определяется
  ползунком; названия старых режимов сохраняются только для чтения настроек.
- IncreasedDamage ограничен максимумом **+8 единиц после расчёта мощности**
  и действует только в собственном одиночном мире со встроенным сервером.
  На удалённом сервере урон определяет сервер; клиентская настройка не добавляет +8.

Четыре класса сетевого исправления `network.1` сохраняются побайтно. Это сохраняет
обработку обязательных серверных сообщений, полной скорости и очереди автоатаки.
Искусственные задержки обязательных пакетов и поддельные движения не добавляются.
Такая проверка не доказывает совпадение трафика с ванильным клиентом и не
гарантирует отсутствие флагов, блокировок урона или бана на RaidMine.

## Исходники и проверка

Полного исходного кода Pulse в предоставленных материалах нет. Публикуются
исходники собственных изменений, тесты и рецепт проверяемого наложения на
конкретный JAR. Это **не** полная сборка всего клиента из Java-исходников.
Входные файлы фиксируются SHA-256, неизвестная версия отклоняется.

См. `docs/BUILD.md`, `docs/NETWORK-RU.md`, `docs/COMPARISON-RU.md`, `CHANGELOG-RU.md`
и актуальный `verification.json` рядом с результатом сборки. Локальные тесты
с проверочными заменами игровых классов не равны запуску Minecraft или
проверке античита. Проверка на RaidMine и запись сетевого трафика не выполнены.

Присланные конфигурации, переписка, логи, игровые файлы и сторонние клиенты
в архив исходников и релиз не включаются.
