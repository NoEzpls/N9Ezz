# N9Ezz Universal Loader 0.4.1 experimental

Minecraft 1.21.11 / Java 21.

This branch distributes the verified installer requested by the repository owner.
Run: `java -jar N9Ezz-Universal-Loader-0.4.1-experimental.jar`.
External mods require the native `n9ezz.mod.json` format and N9Ezz API.
The embedded client and pinned Fabric API components share one runtime.
Full Forge/NeoForge game patches and arbitrary platform mod support are not implemented.
