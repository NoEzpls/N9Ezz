# 0.2.2 Experimental

Исправлена рассинхронизация при последовательности «Сначала отмените текущую ставку с помощью /cf cancel» → «У вас нет активной ставки». Запрос отмены сохраняет связь с текущим соединением; подтверждённое отсутствие ставки снимает сохранённый признак незавершённости. Помощник остаётся на паузе до нового подтверждённого запуска.

- Убрано влияние чужих сообщений с упоминанием `/cf` на привязку результата. В 0.2.1 такой `OBSERVED_CANDIDATE` мог остановить учёт уже подтверждённой ставки, а последующая личная победа оставалась только наблюдением.
- Добавлена машина состояний `IDLE`, `CREATING`, `ACTIVE`, `SETTLING`, `VERIFYING`, `PAUSED`, `STOPPED`, `ERROR`. Создание, результат и баланс проверяются последовательно; неопределённость блокирует следующую ставку.
- Неизвестная ставка сохраняется до ответа сервера. Признак незавершённости записывается до отправки команды. Ошибка отправки не приводит к повторной команде создания.
- Добавлены однократная проверка `/cfbot verify`, тайм-ауты и журнал переходов. Старый `/cfbot reset checked` больше не может локально стереть неизвестную ставку.
- Мост сохраняет время получения сообщений, а контроллер отдельно использует время обработки для тайм-аутов. Ответ, накопленный до новой команды отмены, не подтверждает её; обычная задержка очереди между тиками не считается переводом часов назад.
- Добавлены одноразовое подтверждение запуска, отдельная фиксированная сумма `/cfbot fixed` и проверка верхнего предела `/cfbot stake`. `start N` допускает максимум N последовательных попыток создания.
- Перед каждой ставкой проверяются баланс, абсолютная цель и возможное превышение лимита чистого убытка при проигрыше. `stop`, отключение и смена сервера не позволяют автоматически продолжить игру.
- Сохранена команда `auto`; в 0.2.2 она использует фиксированную сумму и подтверждение. Повышение суммы по выходу нейросети отключено. Модель сохранена для совместимости состояния и диагностики подтверждённой истории.
- Объединены запросы `/bal`, `balancecheck` и диагностика в контроллере с общим интервалом команд и тайм-аутами на игровых тиках. Из трёх валют считываются только монеты личного баланса.
- Добавлена строгая проверка схемы RaidMine: чистый выигрыш составляет 85% ставки, проигрыш равен ставке; свежий баланс должен точно совпасть с рассчитанным. Иной формат выплаты или изменение комиссии приостанавливает игру.
- Парсер учитывает `┃`, цветовые коды, тысячные запятые и ранги перед ником. Чужой чат и баланс другого игрока не принимаются за личное подтверждение.
- Сохранены имена команд 0.2.1, нативный дескриптор Loader, пятиколоночный TSV, старые ключи состояния и предпочтений. При переносе создаётся однократная копия `state.0.2.1.bak`.
- Добавлены локальный `selftest` и изолированный `dryrun`/`test` без реальных ставок. Кандидаты и неподтверждённые исходы не попадают в статистику побед/поражений.
- Добавлены восстановленные исходники, автономная сборка Java 21, регрессионные тесты, контрольные суммы и описание ограничений.

Основа — предоставленный `N9Ezz-CF-Assistant-0.2.1-experimental.jar`, SHA-256 `652fdcf0c22688f45f739ed365205d02dd2d992628ddd61d8a8d916fb40cc240`. Оригинальных исходников 0.2.1 не было; код восстановлен с CFR 0.152. Репозиторий для получения исходников не использовался.
